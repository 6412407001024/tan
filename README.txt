MY JOURNAL — ตัวอย่างเว็บไซต์บทความหลายหน้า

วิธีเปิดใน VS Code
1. แตกไฟล์ ZIP ไปยังโฟลเดอร์ที่ต้องการ
2. เปิด Visual Studio Code > File > Open Folder > เลือก my-journal-website
3. เปิดไฟล์ index.html และคลิกขวา > Reveal in File Explorer แล้วดับเบิลคลิกเพื่อเปิดใน Chrome
   หรือใช้ส่วนขยาย Live Server ใน VS Code (ไม่บังคับ)
4. คลิกเมนู Home / Articles / About / Contact Us ทดลองเปลี่ยนหน้า

ไฟล์สำคัญ
index.html = หน้าแรก
articles.html = หน้ารวมบทความ มีตัวกรองหมวดหมู่
article-html.html / article-css.html / article-tech.html = หน้าบทความ
about.html = เกี่ยวกับเรา
contact.html = ติดต่อเรา (mailto ไม่ใช่ระบบหลังบ้าน)
css/style.css = สไตล์ทั้งหมด
js/main.js = เมนูมือถือ / ตัวกรองบทความ / ฟอร์มอีเมล

แก้เนื้อหาด้วย VS Code แล้วกด Ctrl+S และรีเฟรช Chrome เพื่อดูผล
หมายเหตุ: ฟอนต์ Noto Sans Thai และ Inter โหลดจาก Google Fonts ผ่านอินเทอร์เน็ต หากไม่มีเน็ตจะใช้ฟอนต์สำรอง

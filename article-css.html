CSS คืออะไร? แต่งเว็บให้สวยและอ่านง่าย

MY JOURNAL · 18 ตุลาคม 2026 · อ่าน 4 นาที
🎨

CSS (Cascading Style Sheets) เป็นภาษาที่ใช้กำหนดรูปลักษณ์ของ HTML ทั้งสี ขนาดตัวหนังสือ ระยะห่าง และการจัดวาง

แยกเนื้อหาออกจากหน้าตา

HTML ทำหน้าที่สร้างเนื้อหา ส่วน CSS ควบคุมการแสดงผล เราจึงแก้หน้าตาทุกหน้าได้ง่ายขึ้นเมื่อใช้ไฟล์ CSS ร่วมกัน

คุณสมบัติที่ใช้บ่อย

  • color เปลี่ยนสีข้อความ
  • background กำหนดสีพื้นหลัง
  • padding กำหนดช่องว่างด้านใน
  • display: grid จัดองค์ประกอบเป็นตาราง

สรุป

เริ่มจากเปลี่ยนสีและฟอนต์ แล้วลองขยับความกว้างเบราว์เซอร์เพื่อดูการจัดวางแบบ Responsive
